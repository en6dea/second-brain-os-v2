# Дизайн-система «Прибор»

## Направление

Измерительный прибор в покое. Не панель управления космическим кораблём, не
таблица, не трекер с наградами. Спокойная поверхность, на которой показания
читаются без усилия, а границы знания видны.

Отправная точка — главное правило продукта: незаполненное не равно нулю. Обычное
финансовое приложение прячет пробел в данных за нулём. Здесь пробел показан.
Отсюда взялась и подпись системы, и выбор шрифтов, и палитра.

## Подпись системы: шкала известного

Под сводными показателями идёт тонкая шкала. Сплошной отрезок цвета акцента —
то, что подтверждено. Штриховка — то, что системе неизвестно. Рядом числа:
«известно 2», «не заполнено 1».

```
Собственные деньги
99 200 ₽
не заполнено: Вклад
▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀░░░░░░░░
известно 2          не заполнено 1
```

Компонент `ШкалаИзвестного` в `src/design-system/components/Data.tsx`.
Штриховка задана токеном `--hatch`, чтобы выглядеть одинаково везде.

## Палитра

Акцент — петроль, цвет патины на приборном стекле. Он выбран вместо привычного
синего или фиолетового: узнаётся, спокоен и не спорит со смысловыми цветами.

| Токен              | Светлая   | Тёмная    | Смысл                    |
| ------------------ | --------- | --------- | ------------------------ |
| `--surface-bg`     | `#eff1f0` | `#111210` | фон окна                 |
| `--surface-card`   | `#ffffff` | `#191b19` | карточка                 |
| `--surface-over`   | `#ffffff` | `#20231f` | окно поверх              |
| `--surface-sunken` | `#e6e9e8` | `#151714` | утопленная область       |
| `--line-soft`      | `#dde1df` | `#2a2d28` | обычная граница          |
| `--line-strong`    | `#c6ccc9` | `#3b403a` | заметная граница         |
| `--ink`            | `#161a18` | `#e8ebe7` | основной текст           |
| `--ink-2`          | `#56605c` | `#9aa39d` | пояснение                |

Фон светлой темы — минеральный, с зеленоватой примесью. Не кремовая бумага и не
холодный белый. Фон тёмной — тёплый графит, а не сине-чёрный.

Смысловые цвета применяются только по смыслу. Приложение не раскрашивается.

## Шрифты

Три роли вместо одной. Один шрифт на всё делает интерфейс безголосым.

| Роль      | Шрифт                  | Где                      |
| --------- | ---------------------- | ------------------------ |
| Заголовок | Golos Text 500–700     | `h1`, `h2`, `h3`         |
| Текст     | Onest 400–600          | абзацы, подписи, кнопки  |
| Показание | JetBrains Mono 400–600 | все числа, класс `.tnum` |

Моноширинный шрифт для чисел — не украшение. Суммы в столбцах не смещаются при
изменении цифр, и вся система читается как показания прибора.

Golos Text и Onest сделаны с кириллицей как основной письменностью, а не как
дополнением.

## Структурный приём: единица измерения

Над показанием стоит надзаголовок с единицей: `₽ · ОСТАТОК`, `ШТ · ЗАДАЧИ`,
`₽ · ЗА МЕСЯЦ`. Он кодирует, что именно меряет число.

Нумерация вида «01 / 02 / 03» не используется. Она уместна только там, где
порядок несёт смысл: в шагах импорта выписки. Там она и стоит.

## Радиусы, тени, движение

Радиусы от 6 до 20 пикселей, сдержаннее обычных. Тени короткие и низкие,
поверхность лежит на плоскости, а не парит.

Движение — одна согласованная последовательность на главной: разделы появляются
по очереди с шагом 60 мс. Шкала известного прочерчивается слева направо за
640 мс. Больше ничего не двигается само по себе. `prefers-reduced-motion`
отключает всё.

## Компоненты

`Кнопка`, `КнопкаИконка`, `Карта`, `ШапкаКарты`, `ТелоКарты`,
`ЗаголовокРаздела`, `Значок`, `Метрика`, `ШкалаИзвестного`, `Полоса`, `Пусто`,
`Загрузка`, `Ошибка`, `Поле`, `Ввод`, `ТекстМного`, `Выбор`, `ВводСуммы`,
`Переключатель`, `Сегменты`, `Окно`.

`ВводСуммы` работает в рублях, наружу отдаёт копейки, пустое поле возвращает
`null`. `Метрика` требует подпись-источник: число без объяснения происхождения не
показывается.

## Правило для новых экранов

Литеральных цветов в компонентах нет. Только токены. Если нужного оттенка нет,
он добавляется в `src/index.css` с именем по смыслу, а не по виду.

Новый экран должен выглядеть так, будто был частью системы с самого начала.

## Тексты

Кнопка называет то, что произойдёт: «Сохранить», а не «Отправить». Действие
сохраняет имя на всём пути: кнопка «Записать платёж» даёт сообщение «Платёж
записан».

Пустое состояние объясняет, что делать. Ошибка говорит, что случилось и как
починить, без извинений. Незаполненное показывается как «не заполнено», а не как
«0».
