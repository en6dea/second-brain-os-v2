# Второй мозг

Личная операционная система: день, цели, привычки, деньги, знания, обзоры.
Работает в браузере без сервера, данные лежат на устройстве.

Вторая версия. Прежняя — [en6dea/second-brain-oc](https://github.com/en6dea/second-brain-oc) —
продолжает работать независимо и не изменяется.

## Запуск

```bash
npm install
npm run dev
```

Приложение откроется на `http://localhost:5173`.

## Команды

| Команда           | Что делает              |
| ----------------- | ----------------------- |
| `npm run dev`     | сервер разработки       |
| `npm run build`   | проверка типов и сборка |
| `npm run preview` | просмотр собранного     |

## Правила, на которых всё держится

Ни одной выдуманной цифры. Каждое число посчитано из записей, рядом указан
источник.

Незаполненное не равно нулю. Остаток счёта `null` означает «неизвестно» и не
входит в суммы. Под сводными показателями идёт шкала: сплошной отрезок —
подтверждённое, штриховка — пробел в данных.

Ни одной мёртвой кнопки. Разделы, до которых не дошла очередь, честно говорят,
что в них будет и на каком этапе.

Деньги хранятся в копейках целым числом. Перевод между своими счетами не доход
и не расход. Платёж по долгу делится на тело, проценты и штрафы, и основной долг
уменьшает только тело.

## Данные

IndexedDB, база `ВторойМозг2`. В `localStorage` — только выбранная тема.

Копии: Настройки → Резервные копии. Перед заменой данных и перед переносом
приложение само сохраняет файл с текущим состоянием.

Перенос из прежней версии: Настройки → Перенос из прежней версии. Исходный файл
не изменяется, сначала показывается предпросмотр.

## Что готово

Главная, разбор, задачи, цели, привычки, календарь, дневник, знания, обучение,
люди, обязательства, торговля, обзоры, аналитика, настройки и раздел финансов
целиком: обзор, счета, операции, категории, бюджет, импорт банковской выписки,
сверка остатков.

В планах остались проекты, планирование и опыт месяца.

Остальные разделы перечислены в [docs/ROADMAP.md](docs/ROADMAP.md).

## Безопасность

В репозиторий не попадают: ключи, резервные копии с личными данными, банковские
выписки, снимки экрана сделок, личные документы. Список — в `.gitignore`.
